# AIL Errors Register (Project)

Реестр ошибок, которые нельзя повторять в этом проекте.
Файл обязателен к чтению в начале каждой сессии.

## Ошибки, которые нельзя повторять

1. Не закрывать задачу без проверки end-to-end.
   - Для интеграций: inbound -> обработка -> outbound.

2. Не делать вывод по одному источнику.
   - Сверять код, runtime-логи и фактические внешние события.

3. Не пропускать проверку на тихий откат файлов.
   - После критичных правок проверять ключевые маркеры в файле и `git diff`.

4. Не считать "сообщение дошло" завершением.
   - Если нет ответа/действия на выходе, задача не считается завершенной.

5. Не оставлять важные выводы только в чате.
   - Фиксировать в `ailog.md`, чтобы контекст сохранялся между сессиями.

## Мини-чеклист перед ответом "готово"

- Измененный код действительно активен в runtime.
- Релевантные тесты пройдены.
- Проверен рабочий сценарий пользователя.
- Нет противоречий между логами, состоянием и поведением.
- Ключевые итоги записаны в `ailog.md`.
